1. The ROS 2 version of the `inspire_hand` package supports the use of Inis Robotics company's dexterous hands and mechanical grippers on the ROS platform. We have only tested this in the Ubuntu 22.04 ROS 2 Humble environment. Other ROS environments must await our subsequent tests.

2. To ensure the program runs correctly, the following environment configuration steps must be performed (only required for the first execution, not needed if already configured):

    1) Install the ROS 2 Humble environment, the specific installation method is as follows:
        (1) Use the FishROS (小鱼ROS) one-click installation, refer to the installation process: `https://blog.csdn.net/weixin_55944949/article/details/140373710?fromshare=blogdetail&sharetype=blogdetail&sharerId=140373710&sharerefer=PC&sharesource=weixin_60461072&sharefrom=from_link`

        Installation process is to download the script:
        ```bash
        wget [http://fishros.com/install](http://fishros.com/install) -O fishros && . fishros
        ```
        (2) Install the modbus library, terminal command:
        ```bash
        sudo apt-get install libmodbus-dev
        ```
    Note: If other dependencies are missing, download the missing compilation items based on the terminal error messages during cmake compilation.

    2) Create a catkin workspace
        Terminal commands:
        ```bash
        mkdir -p ~/inspire_hand_ws/src
        cd ~/inspire_hand_ws
        colcon build
        source install/setup.bash
        ```
        (Use this in every terminal session, it helps you find the ROS installation directory)

    3) Place `inspire_hand_ros2.zip` into the `/src` directory under `inspire_hand_ws`, then unzip it.
        Terminal commands:
        ```bash
        cd ~/inspire_hand_ws/src
        unzip inspire_hand_ros2
        ```
        Move the extracted `inspire_hand_modbus_ros2` and `service_interfaces` to `inspire_hand_ws/src`, and delete the `inspire_hand_ros2` folder.

    4) Recompile the packages
        Terminal commands:
        ```bash
        colcon build --packages-select service_interfaces
        colcon build --packages-select inspire_hand_modbus_ros2
        ```
    Note: Try to avoid using `sudo gedit ~/.bashrc` to add excessive source commands to the bash file, this prevents environment variable conflicts. Minimize duplicate package names (like "service_interfaces"); otherwise, it may lead to errors in message format references or node startup failures.

3.1 Dexterous Hand Usage

    1) Use a network cable to connect the inspire_hand to the corresponding host computer. Modify the IPv4 address to: 192.168.11.222, and the subnet mask to 255.255.255.0. If pinging 192.168.11.210 returns data, the connection is successful. Otherwise, check if the line connection is normal.

    2) Start using the `inspire_hand_modbus_ros2` package
        Note: You must open a new terminal and execute the terminal commands:
        ```bash
        source install/setup.bash
        ros2 run inspire_hand_modbus_ros2 hand_modbus_control_node
        ```

    (1) Set ID (id range 1-254)
    ```bash
    ros2 service call /Setid service_interfaces/srv/Setid "{id: 2, status: 'set_id'}"
    ```

    (2) Set baud rate (parameter redu_ratio range 0-4)
    ```bash
    ros2 service call /Setreduratio service_interfaces/Setreduratio "{redu_ratio: 0,id: 1, status: 'set_reduratio'}"
    ```

    (3) Set six driver positions (parameter pos range 0-2000)
    ```bash
    ros2 service call /Setpos service_interfaces/srv/Setpos "{pos0: 1000,pos1: 1000,pos2: 1000,pos3: 1000,pos4: 1000,pos5: 1000,id: 1, status: 'set_pos'}"
    ```

    (4) Set speed (parameter speed range 0-1000)
    ```bash
    ros2 service call /Setspeed service_interfaces/srv/Setspeed "{speed0: 1000,speed1: 1000,speed2: 1000,speed3: 1000,speed4: 1000,speed5: 1000,id: 1, status: 'set_speed'}"
    ```

    (5) Set dexterous hand angle (parameter angle range 0-1000)
    ```bash
    ros2 service call /Setangle service_interfaces/srv/Setangle "{angle0: 1000,angle1: 1000,angle2: 1000,angle3: 1000,angle4: 1000,angle5: 1000,id: 1, status: 'set_angle'}"
    ```

    (6) Set force control threshold (parameter force range 0-1000)
    ```bash
    ros2 service call /Setforce service_interfaces/srv/Setforce "{force0: 0,force1: 0,force2: 0,force3: 1000,force4: 0,force5: 0,id: 1, status: 'set_force'}"
    ```

    (7) Set current threshold (parameter current range 0-1500)
    ```bash
    ros2 service call /Setcurrentlimit service_interfaces/Setcurrentlimit "{current0: 1500, current1: 1500, current2: 1500, current3: 1500, current4: 1500, current5: 1500,id: 1, status: 'set_currentlimit'}"
    ```

    (8) Set power-on speed (parameter speed range 0-1000) (executes after power-off and restart)
    ```bash
    ros2 service call /Setdefaultspeed service_interfaces/srv/Setdefaultspeed "{speed0: 1000,speed1: 1000,speed2: 1000,speed3: 1000,speed4: 1000,speed5: 100,id: 1, status: 'set_defaultspeed'}"
    ```

    (9) Set power-on force control threshold (parameter force range 0-1000) (executes after power-off and restart)
    ```bash
    ros2 service call /Setdefaultforce service_interfaces/srv/Setdefaultforce "{force0: 1000, force1: 1000, force2: 1000, force3: 1000, force4: 1000, force5: 1000}"
    ```

    (10) Set power-on current threshold (parameter current range 0-1500) (executes after power-off and restart)
    ```bash
    ros2 service call Setdefaultcurrentlimit service_interfaces/srv/Setdefaultcurrentlimit "{current0: 1500, current1: 1500, current2: 1500, current3: 1500, current4: 1500, current5: 1500}"
    ```

    (11) Force sensor calibration (This command must be executed twice) (After execution, the hand will fully open, then perform force calibration)
    ```bash
    ros2 service call /Setforceclb service_interfaces/srv/Setforceclb "{id: 1, status: 'set_forceclb'}"
    ```

    (12) Dexterous hand clear error
    ```bash
    ros2 service call /Setclearerror service_interfaces/srv/Setclearerror "{id: 1, status: 'set_clearerror'}"
    ```

    (13) Restore factory settings
    ```bash
    ros2 service call /Setresetpara service_interfaces/srv/Setresetpara "{id: 1, status: 'set_resetpara'}"
    ```

    (14) Save parameters to FLASH
    ```bash
    ros2 service call /Setsaveflash service_interfaces/srv/Setsaveflash "{id: 1, status: 'set_saveflash'}"
    ```

    (15) Read driver set position value
    ```bash
    ros2 service call /Getposset service_interfaces/srv/Getposset "{id: 1, status: 'get_posset'}"
    ```

    (16) Read set dexterous hand angle value
    ```bash
    ros2 service call /Getangleset service_interfaces/srv/Getangleset "{id: 1, status: 'get_angleset'}"
    ```

    (17) Read set force control threshold
    ```bash
    ros2 service call /Getforceset service_interfaces/srv/Getforceset "{id: 1, status: 'get_forceset'}"
    ```

    (18) Read current current value
    ```bash
    ros2 service call /Getcurrentact service_interfaces/srv/Getcurrentact "{id: 1, status: 'get_currentact'}"
    ```

    (19) Read driver actual position value
    ```bash
    ros2 service call /Getposact service_interfaces/srv/Getposact "{id: 1, status: 'get_posact'}"
    ```

    (20) Read actual dexterous hand angle value
    ```bash
    ros2 service call /Getangleact service_interfaces/srv/Getangleact "{id: 1, status: 'get_angleact'}"
    ```

    (21) Read actual force
    ```bash
    ros2 service call /Getforceact service_interfaces/srv/Getforceact "{id: 1, status: 'get_forceact'}"
    ```

    (22) Read temperature information
    ```bash
    ros2 service call /Gettemp service_interfaces/srv/Gettemp "{id: 1, status: 'get_temp'}"
    ```

    (23) Read fault information
    ```bash
    ros2 service call /Geterror service_interfaces/srv/Geterror "{id: 1, status: 'get_error'}"
    ```

    (24) Read set speed value
    ```bash
    ros2 service call /Getspeedset service_interfaces/srv/Getspeedset "{id: 1, status: 'get_speedset'}"
    ```

    (25) Read status information
    ```bash
    ros2 service call /Getstatus service_interfaces/srv/Getstatus "{id: 1, status: 'get_status'}"
    ```

    (26) Gesture sequence
    ```bash
    ros2 service call /Setgestureno service_interfaces/srv/Setgestureno "{gesture_no: 1,id: 1, status: 'setgesture'}"
    ```

    5) ros topic usage example: Read dexterous hand tactile sensor data in real-time
        Requires opening a new terminal and executing the terminal command: `source install/setup.bash`

    1.  `ros2 run inspire_hand_modbus_ros2 handcontrol_topic_publisher_modbus.py`
    2.  `ros2 run inspire_hand_modbus_ros2 handcontrol_topic_subscriber_modbus.py`
    This example will print the sending frequency in the terminal and print the current tactile sensor data for the whole hand in real-time.

    3.  `ros2 run inspire_hand_modbus_ros2 inspire_hand_modbus_topic.py`
    This example will publish topics for setting angle, speed, and force, and reading angle, tactile, force, and motor cylinder temperature.

    topic call example:
    Set angle: `ros2 topic pub -1 /set_angle_data service_interfaces/msg/SetAngle1 "{finger_ids: [1,2,3,4,5,6], angles: [1000,1000,1000,1000,1000,1000]}"`
    Read angle: `ros2 topic echo /angle_data`

    6) ros service usage example: Script calls a service contained in service_interfaces/srv: Setpos
        Requires opening a new terminal and executing the terminal command:
        ```bash
        source install/setup.bash
        ros2 run inspire_hand_modbus_ros2 hand_control_client_modbus_node
        ```
